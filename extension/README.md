# PromptCraft Browser Extension

Generate perfect AI prompts directly on ChatGPT, Claude, Gemini, Perplexity, and Poe.

## Install (Chrome / Edge / Brave)

1. Download or clone this repo
2. Open your browser and go to `chrome://extensions`
3. Enable **Developer mode** (top-right toggle)
4. Click **Load unpacked**
5. Select the `extension/` folder
6. The PromptCraft icon appears in your toolbar

## Setup

1. Get a free Groq API key at [console.groq.com](https://console.groq.com)
2. Click the PromptCraft extension icon
3. Paste your API key in the field at the bottom → Save

## How to use

1. Click the PromptCraft icon on any page
2. Describe what you need → Generate
3. Switch between V1 (Detailed) and V2 (Concise)
4. Click **Insert into AI** to paste directly into the current AI tool
5. Or use the floating **⚡ PC** button that appears on supported AI sites

## Supported sites

- ChatGPT (chatgpt.com)
- Claude (claude.ai)
- Gemini (gemini.google.com)
- Perplexity (perplexity.ai)
- Poe (poe.com)
